# Experiment–6: Handle Forms and Validations in Frontend

**Submission Date:** 05th February, 2026
**Technology Used:** React.js + Vite + Material UI (MUI)

---

## Aim

To design and implement a frontend form using **Material UI (MUI)** components in React and apply **in-built and custom validations** for different form fields.

---

## Description

This experiment demonstrates how to handle user input in a React application by creating a form with multiple input components. The form is built using **Material UI (MUI)** for a clean and responsive UI. Proper validations are added to ensure correct and complete user input before submission.

---

## Features Implemented

* Form creation using **MUI components**
* Text Fields with validations (required, email format, length, etc.)
* Checkbox input handling
* Radio Button selection
* Submit button with validation check
* Error messages for invalid inputs
* Responsive and user-friendly UI

---

## Components Used

* TextField
* Checkbox
* Radio / RadioGroup
* FormControl & FormLabel
* Button
* Box / Container (for layout)

---

## Validations Included

* Mandatory field validation
* Email format validation
* Minimum/maximum length checks
* Selection validation for checkbox and radio buttons

---

## How to Run the Project

1. Clone the repository
2. Install dependencies:

   ```bash
   npm install
   ```
3. Start the development server:

   ```bash
   npm run dev
   ```
4. Open the browser and navigate to the local server URL

---

## Output

A fully functional frontend form that validates user input and allows submission only when all validation rules are satisfied.

---

## Conclusion

This experiment helps in understanding how to handle forms in React using Material UI and apply validations effectively. It builds a strong foundation for creating real-world frontend forms with proper user input handling.
